Câu hỏi Thường gặp (FAQ)

Giải đáp thắc mắc về hệ thống Fruvia AI Image Retrieval.

Hệ thống hỗ trợ những định dạng hình ảnh nào?

Fruvia AI hỗ trợ đầy đủ các định dạng phổ biến như JPG, JPEG, PNG, và WEBP với dung lượng tối đa 10 MB mỗi lần gửi.

DINOv2 có ưu điểm gì so với các mô hình phân loại cũ?

DINOv2 học đặc trưng tự thân (Self-Supervised), trích xuất thông tin ngữ cảnh và hình dáng trái cây sâu hơn mà không bị giới hạn bởi danh sách nhãn cố định.

Qdrant Cloud xử lý dữ liệu như thế nào?

Qdrant lưu trữ các vector đặc trưng 768D kèm theo metadata (tên trái cây, tập dữ liệu, đường dẫn) và thực hiện tính toán Cosine Similarity trong thời gian thực.

Tôi có thể tích hợp API này vào hệ thống của mình không?

Có. Backend RESTful API được xây dựng bằng FastAPI với đầy đủ tài liệu OpenAPI (Swagger Docs) cho phép kết nối dễ dàng từ mọi ứng dụng di động hoặc web.
